## Course Overview

Data Structures (CS 2001) at FAST-NUCES. I took the course in Fall 2023 and again in Fall 2024, so the repository has two complete semesters side by side. Each semester has a **Course** folder (slides, assignments, quizzes, exams, books, final project) and a **Lab** folder (weekly lab handouts and my Visual Studio C++ solutions, most of them checked with Google Test).

## Topics Covered

| Unit | Topics |
|---|---|
| **1. Foundations** | Abstract data types, arrays, address calculation, function and class templates |
| **2. Complexity** | Running time analysis, growth rates, Big-Oh, Big-Omega and Theta |
| **3. Searching and sorting** | Linear and binary search, bubble, selection and insertion sort |
| **4. Linear structures** | List ADT, singly, doubly and circular linked lists, queues, stacks, infix to postfix, recursion |
| **5. Trees** | Binary trees, BST, AVL trees and rotations, heaps and priority queues, B-trees, red-black trees |
| **6. Graphs** | Representations, BFS, DFS, minimum spanning trees (Prim, Kruskal), shortest paths (Dijkstra, Floyd) |
| **7. Hashing** | Hash functions, chaining, open addressing, linear and quadratic probing |

## Building the Code

The lab solutions are Visual Studio 2022 projects. Open any `.sln` file and press **Ctrl + F5**. Projects named `Sample-Test1` use Google Test, which NuGet restores on the first build.

Single-file programs also build with any C++ compiler:

```bash
git clone https://github.com/rohaan2802/DSA_Repository.git
cd DSA_Repository
g++ -std=c++17 "Data Structures 24 Fall/Data Structures Lab/Lab #15/i222327_A_lab15.cpp" -o graph
./graph
```
