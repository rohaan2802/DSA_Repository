Overview

Data Structures (CS 2001) at FAST-NUCES. I took the course in Fall 2023 and again in Fall 2024, so both semesters sit side by side. Each has a course folder with slides, assignments, quizzes, exams, books and the final project, and a lab folder with the weekly handouts and my Visual Studio C++ solutions, most of them checked with Google Test.

Unit 1

Foundations & complexity

Abstract data types, arrays, templates, running time analysis, growth rates, Big-Oh, Big-Omega and Theta.

Unit 2

Linear structures

Searching and sorting, array lists, singly, doubly and circular linked lists, queues, stacks, infix to postfix and recursion.

Unit 3

Trees

Binary trees, binary search trees, AVL rotations, heaps and priority queues, B-trees and red-black trees.

Unit 4

Graphs & hashing

BFS, DFS, Prim and Kruskal, Dijkstra and Floyd, hash functions, chaining and open addressing.

Get the Files

Clone everything with Git, then build any lab in Visual Studio or with g++.

Clone the repository

Command
git clone https://github.com/rohaan2802/DSA_Repository.git

Build a single-file program

Command
g++ -std=c++17 "Data Structures 24 Fall/Data Structures Lab/Lab #15/i222327_A_lab15.cpp" -o graph && ./graph

The lab solutions are Visual Studio 2022 projects: open any .sln file and press Ctrl + F5. Projects named Sample-Test1 use Google Test, which NuGet restores on the first build.
